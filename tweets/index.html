今年想改善的兩個缺點：表達與記憶

2026/01/25

本文 100% 由 AI 撰寫

最近在面試，回放自己的回答後，發現兩個我一直忽略的缺點，想先記錄下來，當成今年的改善方向。

1. 溝通表達能力
#

面試官問問題時，我常常會繞了好幾圈，然後其實都在講同一件事。

  • 重點講不清楚
  • 同樣的兩三句話一直重複
  • 回答不夠有說服力

回頭想，其實有更好的說法，但當下可能因為緊張，就沒辦法把它講出來。

這會是我今年很重要的改善方向。

目前還沒有很明確的解法，但我覺得會先從這些開始：

  • 多面試，讓自己習慣被問問題
  • 多看別人怎麼回答，觀察差異
  • 在工作或生活中練習「講重點」

2. 記憶力
#

我的記憶力其實算差，常常是討論完過一兩天，就忘記那次在講什麼，或是具體結論和細節。

當然會做筆記，但我發現做筆記時很容易分心，變成一邊記一邊沒聽懂。

所以我想調整兩件事：

  1. 學會記下真正重要的重點
    • 不要記一堆但沒有重點
    • 練習邊記邊聽，保持互動
  2. 嘗試逐字稿工具
    • 會議先錄音
    • 用逐字稿工具產出全文
    • 再用 AI 整理重點

為什麼不用 Slack？因為我覺得它的逐字稿不準，而且錄音會讓對話變得不自然。

所以我想試試自己的方式，看能不能找到更舒服的做法。

結尾
#

先把這兩個缺點寫下來，是提醒自己：今年要練的，不只是技能，還有「表達」與「記憶」。

希望年底回頭看，能說：我有變好一點。

純粹的人

2026/01/19

我喜歡純粹的人。

如果在有得選的狀況下，我會選擇和純粹的人一起合作。

對我來說什麼是「純粹」？

內外一致：想的、說的、做的差不多
#

純粹的人，通常不太會「演」給別人看。

他可能也會社交、也懂人情世故，但他不會把自己活成一個角色。

動機單純
#

純粹的人，通常做事情更多是因為「我相信這是對的」或「我真心想做」，而不是為了交換、算計、收買人心。

赤子之心
#

純粹的人常常給人一種「很好讀懂」的感覺。

不是因為他沒城府，而是他不靠隱藏來獲得安全感。

他並非不懂世俗的複雜，而是看透了複雜後，依然選擇選擇簡單。

他可能知道世界有很多灰色地帶，但他仍願意用「清楚、坦然、善意」的方式活著。

自我警惕：不要當「搞不懂的人」
#

今年我在看《內向者的好人緣聊天術：【全日本最內向的溝通技巧講師親授】掌握47個對話黃金心法，輕鬆融入每個圈，跟誰都能聊得來！》這本書，裡面提到：

為什麼人們會和「搞不懂的人」保持距離？

因為對於不了解的事物，人的內心會先入為主抱持負面想法，並保持警惕。

對我來說「搞不懂的人」，和「不純粹」其實蠻類似的。

而書中也提到：

人們和「熟悉的人」或「容易理解的人」在一起時，會感到舒適與放心。

雖然看起來很像廢話，但也提醒了我。

過去我常常會把很多話放在心裡不敢講，例如我就是一個超級社恐仔，但有時候會硬著頭皮假裝外向。但難免還是會「露出馬腳」，因為那個就不是真的我。

但後來我發現，與其這樣，不如直接表達自己的想法，例如：「我不喜歡人多的地方，所以我才待在角落。」

這樣自己也很輕鬆，因為沒有戴著一個面具的壓力；而其他人也能充分明白自己行為的動機，而不是一個「搞不懂的人」。

取代自己的第一步：學會表達

2026/01/19

今年不約而同聽到了兩位優秀夥伴跟我說，他們無時無刻都在想「要怎麼把自己取代掉」。

但我後來發現，兩個人執行的方式截然不同，不禁引發我的一些思考。

其中一位的方向是「增加能力值」，他認為自己如果能學會更多技能，就能在職場上更有競爭力，自然就不會「被取代」。

而另外一位的方向是「把自己從重複的勞動中解放出來」，他認為找出事情的規律，並想辦法透過任何手段自動化，他才能有時間和精力學習新技能。

久而久之，我發現第一位好像還是沒辦法做到「取代自己」這件事情，因為他只專注「學會更多技能」，而沒有把工作外包出去，不論是透過 AI 或是人工。

我一直覺得，每個人工作時，大腦都在運行一套「無人知曉的演算法」。

每天做的判斷、處理問題的方式、看重的優先順序、直覺避開的風險 —— 這些東西都不是「結果」，而是一套藏在腦中的規則。

問題是，大多數人只能講出目標：「我想要這個結果。」

卻講不出過程：「我怎麼得到這個結果。」

或許有時候交辦給別人，別人有可能可以透過逆向工程或過去經驗，來「通靈」你的演算法。

但我們都知道，演算法最麻煩的地方從來不在正常流程，而是在 Edge case。

很多時候看起來結果一樣，其實是因為運氣好、場景剛好、變數不多。

一旦遇到例外、遇到模糊地帶、遇到取捨時刻，沒有把邏輯講清楚的人，就會讓整套系統崩掉。

如果無法將這套演算法的邏輯、Edge Cases 與風格文字化，久而久之身上的 Loading 就會愈來愈大，也就不會再有時間可以去學習新的技能。

而我覺得最好的方式，就是平常就要主動的把自己各種決策邏輯給寫下來，並盡可能統整出一套「原則」。

如果想讓 AI 或同事分擔工作，就必須先成為自己大腦的翻譯官。不能被文字化的演算法，就無法被規模化。

把自己寫下來，或許是通往自由的第一步。

當部落格遇上 AI：我的實驗與反思

2026/01/05

本文 100% 由 AI 撰寫

起因
#

懶得咀嚼的人生領悟

2026/01/04
生活

上面這篇關於「懶得咀嚼」的推文其實是我用 Claude Code 寫的。

事情是這樣的：某天晚上我在外面吃飯，突然有個體悟想記錄下來。但問題來了——我的部落格是用 Hugo 架的，平常都要在電腦前用 VSCode 編輯才能發文。不像 Twitter 或 Threads，拿起手機打幾個字就能發布。

這個限制一直困擾著我。我想過做後台系統，但又覺得太麻煩。

直到我想到：何不用 Claude Code？

創作流程
#

整個過程出乎意料地順暢：

  1. 在手機下載 Claude App，切換到 Code 模式
  2. 連接我的部落格 GitHub repository
  3. 用自然語言描述我的想法：「我剛剛有個體悟…請幫我寫成一篇推文」
  4. Claude 迅速產出中英文版本，並自動發 PR
  5. 在手機上 review PR，發現需要修改的地方直接跟 Claude 說
  6. Claude 立即修改並更新 PR
  7. 確認無誤後 merge

全程只需要手機，甚至不用自己寫文章。

解決的痛點
#

這個工作流解決了我長久以來的困擾：

  • ✅ 隨時隨地都能發文（不再受限於要有電腦）
  • ✅ 不需要建立複雜的後台系統
  • ✅ 連文章都不用自己寫（AI 根據我的想法產出）

對於想隨手記錄想法的我來說，這簡直完美。

發現的問題
#

但實際使用後，我也發現了一些問題：

1. AI 會虛構內容
#

文章裡有些細節不是我當初講的，是 AI 自己「腦補」出來的。雖然不影響主旨，但確實不是 100% 我的原話。

2. 文字風格的落差
#

如果長期用這種方式寫作，部落格的用詞和語氣會跟我本人有差異。雖然概念出自我，但表達方式是 AI 的。

3. 模型本身的限制
#

Claude Code 目前使用的模型不支援圖片生成。當我需要為文章製作封面圖時，無法直接請 Claude 一併處理。

這讓創作流程少了一點彈性——如果能連封面圖都一起生成，那就真的是完全手機搞定了。

或許未來可以試試其他支援文生圖的 AI 工具（例如我之前用過的 Google Antigravity），看能否找到更完整的解決方案。但短期內，目前的方案已經夠用了。

這讓我想起最近看到胡立老師的文章：《AI 與鴨子，惰性與真實》，裡面提到一個很重要的觀點：

「不是所有 AI 都可以代勞的事情，都應該交給 AI。」

現在看起來，我的發文流程好像全部給 AI 做就好。但我真的想要這樣嗎？

我的決定
#

經過這次實驗，我想清楚了：

  • 大部分的文章，我還是會自己寫

    • 因為寫作本身是一種表達練習
    • 記錄生活的過程也很重要
    • 我想保持自己的文字風格

  • 偶爾會讓 AI 代筆

    • 當我在外面突然有想法，但懶得完整寫作時
    • 當我真的很懶，只想快速記錄概念時

對我來說，部落格最重要的是「傳達我的想法」和「記錄我的生活」。至於是不是由 AI 寫，目前還不是最重要的事。

但我也想練習表達、練習用文字敘述。所以不會完全依賴 AI。

結語
#

這是一次有趣的實驗。技術確實帶來了便利，但也讓我重新思考：什麼才是我真正想要的？

或許答案是：保持彈性。讓 AI 成為工具，而不是替代品。

有時候自己寫，有時候讓 AI 幫忙。重要的是，這些文字最終都來自我的思考和生活。

畢竟，能懶的事情可以懶，但不該懶的事情，還是別懶了吧 😊

留下麵包屑

2026/01/03

最近在整理履歷時，不禁有感而發。

因為過去沒有養成隨手紀錄的習慣，導致現在必須回頭翻閱海量的 Ticket 和 Merge Request 來回憶自己做過什麼，雖然有用 AI 輔助，但過程還是耗費心神。

恰好最近看到一些感人的影片，人們透過 AI 技術將過往的老照片轉化為動態影像（例如重現婚禮現場、孩子出生的瞬間）。這讓我意識到一件事：在 AI 技術突飛猛進的今天，我們擔心的不該是 AI 不夠強大，而是我們是否擁有足夠的「素材」供 AI 分析？

試想，如果我們只能提供學歷、工作經歷或是當下的片面想法，AI 分析出的「我」恐怕也只是一個扁平的輪廓。但若能提供長期的日記、面對挫折時的心境轉折等深層數據，AI 就更有機會精準地解讀我們，甚至提供有價值的建議。

除了替 AI 準備素材，我也想起曾聽過一句很有道理的話：

「大腦是用來思考的，不是用來記憶的。」

職場的本質就是各取所需

聽這集蠻有共鳴的，做些筆記。

如何看待工作
#

我們在職場並不是要找 Mr. Right，也不可能找到 Mr. Right，一定難免會有一些不順眼的地方。

但現在的老闆和公司如何，是他們自己的課題。不要試圖去改變「企業文化」，Bryan 比喻企業文化如同「滷汁」，個體進入其中只會被同化，連老闆本人都不見得能夠改變企業文化。若不認同文化，就直接離開就好。

我們應該把目光聚焦在自己身上，把自己當成一間獨立的公司，跟現在的公司 B2B 合作，專注在拿到我們想要的東西，不管是能力、金錢、地位、人脈、名聲等等。

我們應該不斷的問自己：「一年、兩年、五年…後，我希望成為什麼樣子。」，想好了之後倒推自己現在應該要做什麼事情。

在進到一間公司的之前，可以做兩件事情：

  • 預設每份工作都只待兩年：兩年時間其實相當於讀一個碩士的時間
  • 維護一個「目標清單」：把這兩年想從這間公司獲得的東西都寫下來

如果目標都已經完成，然後沒有新的目標，那就是尋找下一個合作夥伴的時機了。

這其實和我近期在實行的做法很類似，我也有一個清單，記錄著我對「技術部門的長遠規劃和產品規劃」。

這個清單上面簡單區分成：

  • 產品相關
    • 功能性：我有興趣實作的功能、我覺得能替公司創造最多價值的功能
    • 非功能性：例如重構、優化、架構設計的等等
  • 開發流程相關：例如優化開發速度、避免技術債囤積等等

在平常的時候，除了日常工作之外，我就會把時間投資在這些議題上面。

當我發現在公司實在太難推動，或是長期沒辦法讓我做我想做的東西時，我可能就會慢慢考慮離開。

這也不代表公司的方向是錯的，但就是我沒辦法得到我想要的技能。

職涯倦怠
#

此外，Bryan 也有提到他如何克服職涯倦怠。

他提到他會紀錄工作事項，進行 -10 ～ +10 的開心評分。

長期下來就能觀察到自己到底喜歡做什麼事情，認清自己的天賦和熱情所在。

而要消除倦怠，可以考慮兩個維度：

  • 縱向發展： 做得更深（例如：從蓋 10 層樓挑戰 30 層樓）。
  • 橫向拓展： 服務更多對象或學習延伸技能（例如：工程師去學防火、建築美學）。

不過 Bryan 也有提到，不要盲目跨行，不建議在未具備基礎下直接轉行（如：工程師轉甜點師），這通常只是對現狀的逃避，挫敗率極高。

離職藝術
#

理想的離職應該是因為看到更好的目標， 而非僅因為討厭現狀。

所以認清自己要什麼還是做重要的事情。

此外，Bryan 特別提到，不要因為「加薪挽留」而留任。若因老闆加錢才留下來，在老闆心中的價值將淪為可以用錢隨時買斷的籌碼，未來升遷機率極低，而且其他同事也許也會有異樣的眼光。

健康的態度是爽朗地感謝公司，並堅持走向下一個生涯階段

結語
#

感謝 Bryan、感謝博恩讓我聽到這麼好的節目。

雖然跟我今年的體悟類似，但我就沒有辦法這麼有系統性的講出來。

希望能幫助到正在閱讀的你。

或許我真的不適合早起

2025/12/08

最近幾年，「早起」好像成為了成功人士的代名詞。

不乏有很多 KOL 都透過影片描繪了早起所帶來的美好，也有很多研究成功人士的書籍，並指出他們的共同點之一就是早起。

然而，早起真的有這麼好嗎？真的適合每個人嗎？

過去我多次嘗試早起，但在今年我終於發現：我真的就不適合早起。

早起的好處
#

不論是書籍、影片在闡述早起的時候，不外乎提到以下幾點：

早上最不容易被干擾
#

確實如果夠早的話，其他人根本還沒起床。但相對的，晚上夠晚的話，也不會被打擾。

而且，也不是每個人真的都能很早睡。

像我自己很喜歡打泰拳，大部分泰拳課程都是晚上的。就算我想改成早上打也不行。

所以就變成要早起的話，我就得放棄我的興趣、改成早上運動、訓練更早起床。

早上是思考最清晰的時候
#

睡覺剛起來的時候，還沒接觸到生活中的各種雜訊，這時候是專注力最強的時候。

而且因為剛睡醒，所以精神很好。

但對我來說，卻不是這樣。晚上才是我思考最清晰的時候。

我也不知道為什麼，正常情況來說，我的精神曲線是從起床一路慢慢爬升，然後會有一個瞬間突然掉落，也就是我該睡覺的時候。

聽起來很不可思議，但大概晚上 10 點到凌晨 1 點是我精神最好的時段。

此外，生活中的雜訊其實不只是當天而已，昨天的雜訊也可能會影響。除非一早起來能把今天以前的煩惱全部拋諸腦後，但現實就是不可能。

早起運動身體的激素會…
#

也有人說早上運動，會有激素分泌，所以會有精神 XXOOO 的（請原諒我從來沒真的看懂）。

我自己親自嘗試多次的經驗是：0。

精神沒有好，反而運動完更想睡。

而且運動表現也不好，運動的時候昏昏沈沈的。

晚上也沒有因此睡比較好，該失眠一樣會失眠。

重要的是早起要做什麼
#

很多人會說，要先幫早起訂一個目標、設定一件要做的事情，這樣才不會早起結果根本也毫無成長。

但經過我自己實驗，早起直接工作是效率最高的。

為什麼？前面有提到我早上就是昏昏沉沉的，所以真的很難有意志力去做那些困難的事情。

很多時候我都是滑滑手機、做做家事，結果上班時間就到了。那我早起的意義何在。

可能有人會說：「那你就是意志力不夠啊。」

這點我 100% 同意，但同樣的事情其實放在晚上，我就有動力做了。

此外，工作對我來說也有強制醒腦的作用，因為工作逃不掉，我就是得去處理事情。

不過我可以透過早上先進行一個簡單的復盤，或先做簡單的事項，慢慢醒腦。

結語
#

其實回想過去我成長最快速的時期，沒有一次是因為早起的。反而我成長快速的時候通常都是 1~2 點睡覺。

然後我今年下定決心分析一下，決定不再 Follow 這個「早起成功學」，接納我自己的生理和習慣。

希望這篇文章可以帶給同樣被早起所困的你一些參考😂

為什麼我光頭？

2025/11/22

這幾年只要是第一次見到我的人，都會問我：「為什麼你要剃光頭啊？」

所以用這篇文章稍微整理一下我的思路XD 以後有人問就直接貼文章給他（？

需求分析
#

或許可以從頭髮的用途來進行思考：

  1. 給別人看，可以再細分為兩種：

    a. 專業用途：有些工作可能需要給客戶一個「專業」的第一印象，有時候髮型確實是能加分的

    b. 吸引異性/同性

  2. 給自己看：自己看的開心

  3. 保護頭皮/保暖

首先第一個是專業用途，我的工作基本上都是待在家裡，跟同事的交流全部只有聲音。

再來是吸引異性/同性，我覺得確實有這個效果。但我自己很少出門，出門的時候也不會想要跟別人有過多交集，也沒有吸引異性/同性的需求。

第二個是「給自己看」，老實說看到自己的頭髮很帥，我是會蠻開心的。但我自己光頭也還算好看（自己講）

第三個是保護頭皮/保暖，其實我覺得我光頭的時候頭皮反而更健康了。保暖的部分，台灣天氣這麼熱……如果真的冷到需要頭髮，那乾脆直接戴帽子更快。

成本分析
#

那我們可以來分析一下「留頭髮」和「光頭」的成本。

  • 時間：
    • 理髮：通常如果髮型要好看，可能 3～4 週就要去找設計師報到。但找設計師，可能要預約、出門、等候、回家……，這些全部都是時間。反之光頭我只要在洗澡的時候花個兩分鐘處理就好。
    • 維護：為了讓自己的髮型好看，可能早上要提早起來洗頭、做造型。而且每天晚上洗頭髮、吹頭髮的時間也會拉長。如果是光頭的話，洗完澡擦一擦就好了，早上可以睡到飽XD
  • 金錢：
    • 理髮：好的設計師通常收費不便宜。反之光頭的話我買一個不到 1000 的電動剃頭刀，可以用至少一年。

看到這裡有人可能會說，那去百元快剪，剪那種好整理的髮型就好啊？快又省錢。

其實我大學的時候有實驗過，比較適合我的髮型，通常都比較「搞剛」。去快剪店剪出來的成果，通常都會讓我覺得不如就光頭吧。

而且我真的很懶得出門，也很不喜歡排隊……

總結
#

我承認，我偶爾還是會想要有一個帥帥的髮型。

但每當我把「成本」和「效益」放在天秤的兩端時，我還是會毫不猶豫的選擇光頭。

……好啦我承認我就是懶😂

獨旅的魅力？

2025/09/17

近幾年，在台灣的社群上，常常看到有人強調自己去哪裡「獨旅」。

在自我介紹中，也有人特別將「獨旅」和「非獨旅」分開，分別列出了自己去的哪些國家是獨旅，哪些是跟其他人去的。

甚至有一群朋友出國，然後講好一個下午自由行動，結果那個下午就算「獨旅」了

這種狀況讓我百思不得其解，對我來說，旅行就是旅行，無論是一群人互相分享喜悅，還是一個人享受自由，我都樂在其中，從沒想過要特別把旅行再做區分。

如果是創作者的話還可以理解，畢竟可能有人需要找適合一個人去的店家。

但對一般人來說，似乎是有點沒必要？

不禁好奇「獨旅」這個詞，是有怎麼樣的魅力呢🤔

於是我拿著這個問題跟 Gemini 討教了一番，以下摘錄：

簡單來說，「獨旅」這個詞的魅力，已經超越了「一個人旅行」這個行為本身，而是被賦予了更多關於個人成長、獨立與生活態度的含義。

我們可以從以下幾個層面來理解它的魅力：

  1. 自我探索與成長的象徵

在現代快節奏、高壓力的社會中，我們很少有時間真正與自己獨處、對話。「獨旅」創造了一個完美的機會，強迫我們脫離熟悉的社交圈和舒適圈。

  • 獨立解決問題的能力： 從規劃行程、預訂住宿、到應對突發狀況，所有事情都必須獨力完成。每一次成功解決問題，都會累積成巨大的成就感與自信心，這是在團體旅行中難以獲得的體驗。

  • 深度的內心自省： 沒有旅伴可以聊天分心時，您會有更多的時間思考。旅途中的所見所聞，更容易觸發對自己人生、價值觀的反思。很多人在獨旅後，會感覺對自己未來的方向更加清晰。

  1. 「完全自由」的極致體驗

團體旅行，即使是和最親密的朋友，也免不了需要協調與妥協。今天誰想去博物館、午餐要吃什麼、要逛街到幾點……這些都是甜蜜的負荷。

  • 無需妥協的自由： 獨旅意味著100%的自主權。你可以睡到自然醒，也可以為了拍日出而凌晨四點起床。可以花整個下午在咖啡廳看書，也可以臨時起意跳上火車去一個沒聽過的小鎮。這種「完全為自己而活」的感覺，本身就是一種奢侈的享受。

  • 擁抱不確定性的勇氣： 一個人的旅行，更容易遇到預期之外的人事物。因為只有自己，所以心態會更開放，更願意與當地人交流、嘗試新事物。這份未知與驚喜，是獨旅最迷人的部分之一。

  1. 社交媒體上的「認同標籤」

這也解釋了為什麼社群上大家會特別強調「獨旅」。在個人品牌化的時代，我們所做的事情，都在形塑別人眼中的我們。

  • 勇敢、獨立的形象： 說自己「正在獨旅」或「喜歡獨旅」，等於在告訴別人：「我是一個獨立、有主見、不害怕孤單、勇於挑戰的人。」這是一個非常正面的社交標籤。

  • 尋找社群歸屬感： 透過 #獨旅 這樣的標籤，可以找到有相同經驗和價值觀的同好，形成一種線上社群的歸屬感。分享獨旅的技巧、心得，本身也是一種社交行為。

不確定其他人看到這個分析覺得有沒有道理，我覺得前兩點比較像是在分析獨旅的差異，而我認為第三點的「認同標籤」有解答到我的疑惑。

不過如果真的是這樣的話，我倒是覺得有點可惜的。

《論語》裡面有這麼一句話：

始吾於人也，聽其言而信其行；今吾於人也，聽其言而觀其行。

大意就是在說：起初我對於人，聽了他講的話，就相信他的行為；現在我對於人，聽了他講的話，還要觀察他的實際行為。

例如有人瘋狂吹加密貨幣很好，一直叫別人投資，但自己一顆沒買。這就是很典型的「嘴巴說不要，但身體很誠實」。

而同樣的，有人說自己能享受孤獨，卻又需要在社群媒體上刻意幫自己貼上一個標籤……那還能算是享受孤獨嗎？

我覺得這種「我很獨立，但我希望你們知道我很獨立。」其實反映了內心的某種不安全感。

真正的強大通常是安靜的，不需要透過廣播來證明。

刻意標榜「獨旅」，有時候反而像是一種防衛機制：「你看，我自己一個人也過得很好喔！」

這就像有人一直強調自己「不在乎別人的眼光」，但他強調這件事的本身，通常就代表他其實很在意。

關於成就感

2024/05/04

看到森纳映画的喬伊拍了《【不止遊戲】來跟大夥喝點》這支影片，某句話讓我非常有同感，大意是這樣的：

「因為常常在趕著要週五上片，很多內容都經過了妥協，即使自己內心知道這個作品還不夠好。甚至連自己都不會想要回去再看一次這個作品。」

雖然軟體工程師並不是傳統定義上的創作者，但我覺得心情是類似的。

我不算是技術狂熱者，但自認也算是蠻熱愛寫 Code 的。

有段時間我常常在趕 Deadline，測試過了，功能也正常，客戶也在使用了。

但我內心卻對我寫出來的東西不滿意，我知道有些地方應該要再被優化，或是應該要做什麼事情，讓後續更好維護。

但 Deadline 到了就是到了，導致我自己做出來的東西，自己都不想用。

久而久之，寫程式不再是一件有成就感的工作了。

原本下班之後我還會花很多時間精進自己，但那時真的完全提不起勁看任何東西，只能強迫自己去打遊戲消磨時間。

雖然後來是有重新找回熱情，不過這段經歷也讓我知道我不適合怎樣的環境。
