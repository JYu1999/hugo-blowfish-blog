Here are the shortcuts I frequently use in PHPStorm / RubyMine.
The commands are based on **macOS**; Windows users can simply substitute with <kbd>Ctrl</kbd>.

## Search
- <kbd>&#8679;</kbd><kbd>&#8679;</kbd> : Search EveryWhere
  
    Allows you to search across all files.
- <kbd>&#8679;</kbd> + <kbd>Cmd</kbd> + <kbd>F</kbd> : Find in path (Full-text Search)

    Full-text search across the entire project.
---

## View
- <kbd>Cmd</kbd> + <kbd>&#8679;</kbd> + <kbd>F12</kbd> : Toggle Maximize Editor

    Close/Open all windows except the Editor (distraction-free mode).
- <kbd>option</kbd> + <kbd>F12</kbd> : Toggle Terminal

    Open/Close the terminal.
- <kbd>Cmd</kbd> + <kbd>1</kbd> : Project View

    Open/Close the Project file list.
- <kbd>Cmd</kbd> + <kbd>2</kbd> : Database View (This is not default; I customized it)

    Open/Close the Database View.
---

## Navigation
- <kbd>Cmd</kbd> + <kbd>E</kbd> : Recent File

  Recently accessed or edited files.
- <kbd>Cmd</kbd> + <kbd>B</kbd> / <kbd>Cmd</kbd> + Click : Go to declaration

  Navigate to where this method or variable is declared.
- <kbd>option</kbd> + <kbd>Cmd</kbd> + <kbd>&#8592;</kbd> / <kbd>&#8594;</kbd> : Navigate back/forward

  Return to the previous navigation point or move to the next one (if available).
---

## Files
- <kbd>Cmd</kbd> + <kbd>&#8593;</kbd> : Select File (Navigate in Project View)
- <kbd>Cmd</kbd> + <kbd>N</kbd> : Create New File

---

## Clean Code
- <kbd>Cmd</kbd> + <kbd>&#8679;</kbd> + <kbd>option</kbd> + <kbd>L</kbd> : Reformat Code

  After pressing this, a menu will appear allowing you to choose whether to reformat only the selected code or the entire file.
