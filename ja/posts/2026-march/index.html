3月はとても早く、何も感じないうちにあっという間に過ぎてしまいました！

日付を見て初めて、「やばい、まだ振り返りを書いてない！」と突然気づきました。

急いで補習しますXD

この記事はできるだけ全部自分で書きたいと思います。最近は何でもAIに執筆を代行させていたので、しばらく文字を書いていない気がしますXD

まずは反省から…
#

面接
#

先月の振り返りでは面接を続けると言っていましたが、今月は色々見ても興味を惹かれるものがなかったので、履歴書は送りませんでした。

よく考えてみると、私の今の仕事は、業界、仕事内容、勤務形態、企業文化、チームの雰囲気などを含め、私の理想の状態に非常に近いです。

それに、会社はまだ成長中で常に新しい課題や機会があるので、退屈だと感じることはありません。

以前面接を始めようとした3つの動機を少し振り返ってみました。

  1. 今の会社に長くいる気がして、技術的な学習が減っているように感じたため、新しい環境を試してみたい。
  2. 将来現れるかもしれない夢の求人のために、面接スキルの練習。（自分をどう売り込むか、能力をどうアピールするか、技術的な質問にどう答えるかなど。）
  3. 単一の会社に縛られないように、市場の相場を把握しておきたい。

第一の点はもう成り立たないことに気づきました。実際、会社自体が成長を止めている状態でない限り、技術的な観点からまだまだやれることはたくさんあると後になって気づいたからです。

どこで聞いた意見か忘れましたが、「需要がないのではなく、生産能力の懸念から提案されていないだけ」だそうです。

注意深く探せば、既存の製品やチームのプロセスの不足点を見つけることができ、それを解決しようと挑戦できるはずです。

以前退屈だと感じたのは、自分を「バックエンドエンジニア」に限定し、バックエンドに関する事しか考えていなかったからだと思います。（これがフラグにならないことを祈ります 😂）

1月に「Fake it till you make it（成功するまでふりをしろ）」の概念について触れました。何かの役割になりたいなら、今の自分を直接「すでになった」ものとして扱い、その役割の視点から直接判断を下すというものです。

自分をSREリーダー、エンジニアリングマネージャー、AIエンジニア…などの役割に直接置いたとき、できることが山のようにあることに気づきましたXD

第二と第三の需要は依然として存在しますが、今の私にとっては急いで準備する必要はないようで、ゆっくり進めればいいです。

今後も少しずつ見ていくつもりですが、同じく興味があるものにだけ応募する予定です。

語学
#

元々今月は少し時間をかけて日本語をしっかり練習しようと思っていましたが、約1週間で諦めました。

達成感が少し足りなかったからだと思います。実は日本の番組をあまり見ないので、興味のないものを無理に探して見たくはありませんでした。その結果、学んだのに使う機会がない状態になりました。おそらく、次に日本に行くまで使えないでしょう。これでは達成感のフィードバックが遅すぎます。

以前ベトナム語を学んだ経験を少し振り返ると、教室に行って他の人と交流する方がより多くの達成感を得られた気がします？

ですので最近は、語学に関してはコースなどに申し込むことを検討しています。他の人と交流する方がもっとうまく学べるはずです。

ただ、これから1ヶ月海外に行くので、これは帰国後に実行することになるでしょう。

しかし私の経験上、新しい国に行くたびに、その国の言語を学びたくなるものです（？

副業
#

現在も主力となる2つの副業を維持しています。その一つは彼女のデザートショップ：Lightsom Dessert（少些甜點）です。

このデザートショップの計画は実は前から考えていたのですが、今年になってついに二人で計画を実行することに決めました。

現在、この計画には品目、店舗の形態、ターゲット層など、明確な方向性がまだありません。私たち二人はこの分野では初心者なので、当面は市場とオンライン販売を中心にゆっくり実行し、ついでに新商品の研究開発を行う予定です。

私の手作りスキルは非常にひどいので、主にデザート作り以外の事、写真撮影やマーケティングなどをサポートする予定です。

もう一つは私個人のささやかな趣味で、具体的に何かは言いませんが、パーソナルブランドのようなものになるでしょう。

正直なところ、この趣味をどうやって事業にするか、この事業の最終的なビジョンはどうなるのか、まだよくわかっていません。今は第一歩を踏み出すのを少し躊躇しています。

現在、浅い考えで3つの方向性があります：

  1. 情報の収集と共有：個人的な体験や感想を共有する。ちょうど最近Cloudflare の EmDashを見て、遊んでみるのも面白いかなと思いました。
  2. 業界の研究：この業界のあらゆる側面を研究する。
  3. 専門技術の育成：コースに申し込んで専門技術を学ぶことも検討しています。しかし台南ではこうしたコースが少ないようで、台北か海外にしかなく、移動で少し疲れてしまいますQQ

ですので、今のところは1と2から始めるかもしれません。そして2は今の仕事と相互に助け合える部分があるので、これについては追加で評価する必要があります。

仕事
#

実は仕事関連のことは大体記事にまとめているので、簡単に整理し直します：

《あなたの仕事は何ですか？》 という記事で、インスピレーションを受けたことを упоминаしています。

「彼には信じられないようなアイデアがたくさんあります。彼はまず何とかして論理を立てようとします。まだ製品がなくても、彼を支援してくれる人を何とかして惹きつけようとします……ロケットが爆発したとしても、彼はそれを重大な失敗とは思いません。なぜならそれは進展でもあるからです。」

現代は変化が早すぎます。多くのことは完全な計画を立てることはできず、できたとしても役に立たないかもしれません。迅速な反復と修正こそが最も重要です。

《2年以上の勤務後の反省と振り返り》 という記事では、私自身も気付いたことがあります。

あの事件は私に深く認識させました：時間はリスクである。現代のビジネス環境は極めて速く変化します。もし価値を生み出すのに1年かかるなら、その過程でプロジェクトの中止、マネージャーが忍耐を失う、あるいは競合が現れるなどの変数に直面するかもしれません。最終的に具体的な成果を納品できなければ、その過程でのすべての努力と献身は見られません。

だから今月、AIエージェントを導入した後、すぐにエージェントに向けた小さな最適化を始めました：

会社が遂にAIエージェントを導入!! 今週私が行ったいくつかの調整

AI 生産性ツール

そして、将来本当にAIに開発を完全自動化させたいのなら、SREが以前より重要になると思います。

AIが100%正確でない以上、我々には完璧な監視とロールバックの仕組みが必要です。仕組みが完璧であれば、AIのミスを受け入れることができます。なぜなら「間違えてもすぐに通知を受け取り、迅速に修正できる」とわかっているからです。

さらに、最近会社でもSREがいないと少し問題があることに実際に気付いたので、私はその流れに乗って会社にSREを導入しました。しかしこれも、完全な計画の後の調整というものではなく、多くは歩きながら見ているものです：

システム障害に気づくのに1ヶ月かかった話 —— 会社へのモニタリング導入のきっかけと実践

今後は引き続き、この2つの方向に向けて新しい試みや調整を行っていくと思います。何か気づきがあれば、また記事にまとめて記録します。

そして実際にやってみて、「Fake it till you make it」の力をより実感できました。

以前は「SREの仕事をするには、まずSREでなければならない」と思っていましたが、今は逆だと気づきました：SREがSREである理由は、彼がSREの任務を遂行しているからです；だから、誰がSREの任務を遂行しても、その人は実質的にSREであり、他の人がその称号を与えるのを待つ必要はありません。

同じく《2年以上の勤務後の反省と振り返り》という記事で、進捗報告について触れました。同時に、進捗報告の方法を理解するために、オンラインコースにも特別に参加しました：

進捗報告の仕方とは？

2025年12月07日
より良いプロフェッショナルになる キャリア

ここ数ヶ月の実験と調整を通じて、タイムリーで頻繁かつ誠実な進捗報告は、問題を解決する速度を速め、同時にとても楽になり、さらに社内でのプロフェッショナルなイメージを確立できることを実感しました。

また、《2年以上の勤務後の反省と振り返り》で「自分の家の前の雪だけを掃く」ことについても言及しましたが、後になって私は以前、無意識のうちにゼロサム思考で物事を考えていたことに気づきました。

以前は「みんなでパイを大きくする」という考えがあまりなかったので、「あなたを助けても自分には何のメリットもない」とよく思っていました。さらには無意識のうちに、同僚をパートナーではなく競争相手として見ていました。

しかしこの数ヶ月で、私はゆっくりと「羊の毛は羊から出る（利益は結局自分に返ってくる）」と悟りました。私が会社でより良い収入を得たいなら、前提として会社の収益を増やし、コストを減らす必要があります。そして人を助けることは、会社のコスト削減と効率向上につながります。

同時に、人を助けることで自分の能力もさらに上がり、クレジットも増え、私個人にとって百利あって一害なしです。

キャリアの方向性と学習目標
#

AIアプリケーションエンジニア？
#

1月の《2026年1月》で、私は自分自身についてこう気付いたと言及しました：

私は他人やチームがより効率的になるのを助けるのが好きです。

そして、私の人生の核となる原動力の一つが、他人やチームをより良くすることだと気づきました。

今の会社も私の副業も、実はある状況に直面しています：

限られたリソースの中で、どうやってより多くのことを成し遂げるか？

これに対する素晴らしいツールが、AIだと思います。

自分の苦手なことなら、AIに先生になってもらい、どう処理するかをどう教えてもらうか？最初から上手くいくことはあり得ませんが、60点くらいのレベルには到達できるはずで、そこから最適化を続けることができます。

自分の得意なことなら、自分のやっていることをどうやってプロセス化、自動化するか？

現在直面しているペインポイント、解決している問題、そして私の人生の目標を組み合わせると、もしかすると「AIアプリケーションエンジニア」が良いキャリアパスかもしれません。これには以下のものが含まれるかもしれませんが、それに限定されません：

  • AI環境の構築
  • AIを使った社内プロセスの改善
  • AIを使ったコードの生成
  • AIを使ったマーケティング動画などのコンテンツ生成
  • AIエージェントを日常生活に組み込み、生活を改善する

その上、SRE監視処理も行っているバックエンドエンジニアとして、おもちゃを作るためにVibe Codingを使うだけの人や、自分の問題を解決するだけの人よりも優位性があると思います。なぜなら、私が書いたり導入したものは、安定して動く自信があるからです。同時に、AIに向いているものと向いていないものを見分け、AIが使えないものに対しては、自動化されたシステムを構築する能力も持っています。

3つのコアスキル
#

今やりたいことをすべて合わせて、現時点で必要な重要なスキルをいくつかまとめました：

  1. マーケティングとコミュニティ運営：AIアプリケーションエンジニア、デザートショップ、個人的な趣味の3つの事業すべてにマーケティング能力が必要です。これは共通のコアスキルです。
  2. AI活用能力：やるべきことは多く、苦手なこともたくさんあります。AIは自動化を支援したり、私の先生として機能し、さらに私の長期的な人生の目標と合致しています。
  3. ビジネス思考と経営戦略：副業であれ投資であれ、戦略面の思考能力が必要です。これは事業を「やる」から「うまくやる」へと変えるための鍵です。

その他
#

ついでに、興味はあるけれどコアスキルではないものも記録しておきます：

  1. 言語：現在、英語、日本語、ベトナム語、インドネシア語に非常に興味があります。多言語を話せるのはかっこいいと思いますXD。また多言語が話せれば、他国の文化をより深く理解し、現地の人と知り合え、さらには思いがけない協力の機会に出会えるかもしれません？
  2. 実践スキル（家のDIY修理）：実は人と時間を合わせるのがかなり嫌いで、台湾の職人は衛生習慣が悪い人も多く、さらに頼むとなると費用もかかります。だから少し学んで、自分で修理できれば、家の中の多くのことを自分で処理できると考えました。
  3. ムエタイ：これは純粋な趣味ですXD
  4. 栄養学と運動生理学：自分も家族も健康であってほしいので、長期的に体に一番良い食事と運動について、定期的に最新の知識を学びたいと思っています。

終わりに
#

全体として、3月は「少しずつ軌道に乗ってきた」感があり、仕事でも生活でも考え方の転換がいくらかあって、とても良いと思いました。

もちろん、私が熟考し心配しているトピックもまだいくつかあります。例えば：

  • もっと自分を追い込むべきだろうか？今は少し怠けすぎているのではないか？
  • 突然失業したらどうしよう？遅すぎると仕事が見つからないのではないか？
  • 今見えている分野に集中すべきか、それとももっと多様に学ぶべきか？

まあ、これらについては後でゆっくり考えますXD
